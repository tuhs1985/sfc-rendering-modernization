# Tester graphics setup

The private alpha recognizes a pinned SFC executable and an exact graphics
baseline. A tester with the accepted executable and a working local wrapper
stack can receive only the first rejection, with no supported setup path.

Extend the existing read-only preflight to list the graphics differences it
can identify. Follow with a separate, reversible preparation step for a game
copy and validate that workflow on a clean machine. Preserve package and client
integrity, normal launch admission, gameplay behavior and the accepted install.
