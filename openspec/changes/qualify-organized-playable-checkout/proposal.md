# Proposal

## Why

The two source separations pass isolated package preflight, but the developer receipts are stale and no playable package includes the new layout. Requalify through existing tools and prepare a private hands-on checkout without modifying the working alpha.

## What Changes

- Inventory mismatches, retain old receipts and rebuild the already-fixed renderer from current source when required.
- Run established standalone native cohort and light-worker qualification before renewing applicable receipts.
- Assemble a fresh playable private package using the reorganized sources and current qualified binaries/settings; validate its installed path and GPU startup.
- Provide a normal double-click/command entry only once that actual package is prepared.

## Capabilities

### New Capabilities

None; qualification and private build preparation only, `skip_specs: true`.

### Modified Capabilities

None. No rendering, appearance, native fallback, timing or gameplay behavior changes.

## Impact

Ignored local build/qualification outputs, private staging inputs, relevant build tools/tests if a concrete gap prevents safe preparation, handoff and status. Existing private alpha and accepted game remain unchanged. No publication, automatic game launch, exclusions or silent qualification bypass.
