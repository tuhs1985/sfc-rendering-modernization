# Design

Use existing renderer build, native cohort fixture/qualifier, light worker qualifier, portable staging and installed startup GPU check. Archive previous local receipts before replacing them. Track renewed qualification separately from historic sponsor acceptance. Do not approve unrelated old diagnostic workflows merely because the normal native path works.

Initial audit: native cohort has 37 changed inputs among 646 recorded files; light observer has two changes among 32. Development candidate renderer still predates the accepted profiling-off startup correction; existing private alpha contains the corrected binary. Rebuild current source and qualify it rather than packaging the old artifact. Preserve early receiver startup and disabled profiling.

Stage in a fresh private game directory, use explicit current source allowlist, matching native binaries and immutable manifest. Preserve appearance; do not update the old alpha. Check that the functional stager includes compatible runtime libraries, usable game launch path and a simple entry. Add only narrowly necessary staging fixes discovered by actual checks. Native package preflight and standalone GPU startup are prerequisites to asking sponsor to play; actual game controls/shields/destruction remain sponsor verification.
