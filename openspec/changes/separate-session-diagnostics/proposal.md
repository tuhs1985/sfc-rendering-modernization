# Proposal

## Why

The relocated session coordinator still mixes normal untimed replacement with optional capture modes and historical test orchestration. Give production a narrow native-play path while preserving development commands and shared safety/cleanup.

## What Changes

- Keep the normal session coordinator and shared process/graphics lifecycle in application source.
- Move diagnostic argument resolution, observation/cues and result analysis to a development-only session runner.
- Extract functional graphics-file switching from the broad-capture analyzer so normal startup and recovery do not import that diagnostic module.
- Route existing tools to the appropriate entry point; update the installed allowlist, tests, source qualifications and handoff together.

## Capabilities

### New Capabilities

None; existing behavior is reorganized, `skip_specs: true`.

### Modified Capabilities

None. Native capture/rendering, ExtraFrame standard, untimed play, recording defaults, fallback and appearance remain unchanged. External tester graphics preparation stays parked.

## Impact

Application session source, development diagnostic dispatch, graphics transaction helper, release module list, qualification inventories and tests. Preserve the accepted installation and sponsor-qualified organized game copy. No automatic SFC launch, new renderer feature, timing cap or publication.
