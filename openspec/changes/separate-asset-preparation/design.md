# Design

Move parallel_assets, scene_bundle, material_binding, material_library, roughness_maps, mesh_checksum, damage_materials, damage_mapping and break_scene into src/assets. Module names and public runtime APIs stay stable. Extract decode_mesh/_decode_mesh into mesh_decode, retaining live_scene compatibility exports and actual SceneChannel transport. Leave renderer orchestration and transfer code where they are for the following ownership audit.

Extract capture-review-only functions/classes and test comparisons to one development review module. Runtime scene preparation retains its packet reader because current launch uses it to obtain geometry span. Snapshot selection, old image-store verification, capture consumption and streaming experiments are not normal runtime work. Lazy explicit review access is available only when development tools exist; installed normal play never imports it. Existing test/performance semantics, errors and limits remain unchanged. Do not optimize or remove functional input validation.

Application bootstrap/coordinator and standalone qualification expose src/assets before importing helpers. Existing developer module paths forward to the canonical application implementation using the established importlib compatibility pattern, including spec-loaded helper access. Installed allowlist excludes those forwarders and all review tools. Native/source qualification inventories include canonical assets and developer review inputs.

Test legacy/canonical module identity, unchanged task scheduling and image/mapping output, malformed geometry and all existing asset regressions, actual material replacement, shutdown and normal diagnostic-import exclusion. Requalify affected native workers/GPU/package boundaries, test actual installed CPU assets and prepare a separate playable copy. Review current renderer/transfer owners and coupling from local source; record recommendations without moving them or changing synchronization. Keep all implementation changes uncommitted pending sponsor checkout.
