## Handoff operating convention

1. Before handing off, make the repository self-sufficient for a new model:
   record current gate, exact files/commit/worktree, evidence and confidence,
   runtime state, blockers, and one next action. Do not rely on chat or hidden
   reasoning.
2. Stop starting new work before quota exhaustion. Finish or safely park the
   current smallest unit; if a probe is live, restore/remove it and record the
   outcome before leaving.
3. Run the fastest relevant validation, note commands/results honestly, and
   update a **new NEWEST / AUTHORITATIVE CHECKPOINT** above older checkpoints.
4. Keep older checkpoints and linked evidence. Mark superseded historical
   conclusions/configurations explicitly; do not overwrite or delete them to
   make the newest state look cleaner.
5. End the newest checkpoint with exactly one actionable next step and any
   action that the next model must not redo blindly.
