# SFC Remix v0.1.0-alpha.1

**Experimental prerelease. Successful gameplay testing has only been completed
on the author's own computer.** Compatibility and performance on other PCs are
not yet qualified.

This alpha replaces supported SFC ship meshes through RTX Remix while SFC
continues handling gameplay, controls, tactical UI and native effects. Weapon
lights, reversible damage textures and supported destruction/break models are
enabled. ExtraFrame timing is standard. Normal play is untimed.

This release uses **RTX Remix 1.6.1**. It does not contain the experimental UE5
proof or UE insertion work, and it does not replace every rendering family.

## Download and start

1. Download **SFCRemix-v0.1.0-alpha.1.zip** from this release's Assets, plus the
   matching `.zip.sha256` if you want to verify the download. GitHub's automatic
   Source code archives are not the playable package.
2. Make your own separate copy of the supported SFC installation and retain
   your usual installation/saves as a backup. The game is not included.
3. Extract the complete ZIP beside `StarFleetOP.exe`. It adds only
   `SFCRemix-Launch.cmd` and `SFCRemix/`.
4. Double-click **SFCRemix-Launch.cmd**. Approve the Windows elevation prompt
   when requested. First launch checks the graphics setup and may offer
   reversible changes to the DLLs/settings in this game copy. Read that prompt.
5. Play normally. Exit SFC normally and let the launcher finish cleanup.

The download is approximately 487 MiB, around 1 GB extracted, largely bundled
vendor/runtime dependencies. Allow several gigabytes of working/cache space in
addition to the separate game copy. There is no installer and no Toolkit,
Python, PowerShell, Unreal Engine or build-tool installation is needed.

## Requirements

| Item | Requirement / qualification |
| --- | --- |
| Windows | 64-bit Windows. Windows 11 is the only OS successfully tested by this project. |
| Game | The supported SFC: Orion Pirates Community Edition 2.5.6.4 executable. Other EXE revisions are unsupported. |
| GPU | NVIDIA RTX hardware compatible with the bundled RTX Remix 1.6.1 runtime. RTX 4070 Ti is the only GPU successfully tested by this project. |
| NVIDIA driver | **616.92 or newer**. The tested driver is **621.01**. Driver 610.88 is below the runtime baseline and is unsupported. |
| Game graphics path | Hardware D3D11, the required 8x multisampling profile and the game/Remix on the same GPU. First-run setup checks/prepares the supported game-copy profile with consent. |
| Launch permissions | The launcher currently requests Windows elevation when needed for the integration. |

The driver baseline comes from [NVIDIA's Remix release notes](https://docs.omniverse.nvidia.com/kit/docs/rtx_remix/1.6.1-0/docs/changelog/remix-releasenotes.html#platform-driver-requirements).
The package does not install or update graphics drivers, change system-wide
graphics settings, or provide an older-runtime fallback. A GPU verification
failure can indicate an unsupported driver; it does not by itself establish
that the GPU model is incompatible.

Supported executable SHA-256:

```text
4D65761D7DD69EF1504070261B81E9C200C0AF18105033E1C4D2222C62320C29
```

Known stable native sizes: **1024x768, 1280x720, 1366x768, 1440x900,
1600x900 and 1920x1080**. Keep the game/wrapper dimensions consistent. Native
1440p/4K and supersampling are not qualified by this release. Unknown conflicting
graphics proxies may be refused; report the message instead of deleting DLLs
or bypassing checks. Your own game settings, assets, saves, ReShade shaders and
presets stay in the game copy.

## Tested machine

- Windows 11 x64
- Intel Core i7-13700KF
- 32 GB RAM
- NVIDIA GeForce RTX 4070 Ti, 12 GB VRAM
- NVIDIA driver 621.01

This is the **tested configuration**, not a requirement for that exact CPU,
GPU or RAM capacity. Local tests included different ships, carrier/fighter
stress, camera changes, weapons, damage, destruction and mission transitions.
Those results do not establish universal coverage or successful testing on
another computer. Please treat this as an early compatibility alpha.

## Settings, data and restoration

- Editable light/material/image settings are seeded under `SFCRemix/settings`.
  Existing settings are preserved on later launches/ZIP updates. Restart normal
  play after editing them.
- Default launch keeps **no diagnostic run history**. Required working files,
  reusable caches, settings and interrupted-recovery records still use disk.
- Optional `SFCRemix/Troubleshoot.cmd`, or `SFCRemix-Launch.cmd --troubleshoot`,
  retains at most five short reports of 64 KiB each. Reports are local; nothing
  is automatically uploaded. They exclude model/texture payloads and screenshots.
- There is no gameplay timer or diagnostic-storage quota that ends normal play.
- After an interrupted run, close SFC before relaunching for recovery. To restore
  graphics preparation, close SFC and run `SFCRemix-Launch.cmd --restore`.
  After restoration finishes, remove the launcher and `SFCRemix` folder to
  uninstall. Keep any settings you want. Do not remove game assets or saves.

## Known limitations and feedback

Initial base/enhanced appearance can arrive in stages. Some models or break
files remain unqualified. Cloak/transparency and fighter formation counts may
not match native behavior in all cases. Native rendering remains available
when a matching replacement cannot be inserted. This is not a formal project
milestone-completion claim or complete scene replacement.

For reports, include GPU, driver, Windows version, game executable version,
native resolution, models involved and what happened. Attach the optional short
report or a focused gameplay video if useful. Do not upload the whole game,
saves, private settings or captured game models/textures.

Project-authored code is MIT licensed. Bundled vendor components retain their
own licenses and notices under `SFCRemix/notices`. No game assets, captured ship
models/textures, private settings or development captures are included.
