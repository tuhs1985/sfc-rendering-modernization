# M0-RT-003 — Visual Model to Mesh-Owner Linkage

## Technical question

Do stable `t3DVisual_Model` instances select stable `tModel0` LOD/mesh
owners and feed them into the already observed manager source/polygon path and
confirmed generic submission at `0x006AB410`?

## Evidence-supported hypothesis

Static vtable and MSVC RTTI reconstruction establishes:

- vtable `0x007985A4` has RTTI name `t3DVisual_Model`;
- its method at slot `+0x18` is `0x0042FD3F`;
- that method selects a child from `this+0x160+LOD*4` and calls child vtable
  slot `+0x08` at `0x0042FDD2`;
- vtable `0x007983E8` has RTTI name `tModel0`;
- its slot `+0x08` is concrete method `0x0042E4B2`;
- M0-RT-002 observed `0x0042E4B2` configuring manager source slots before
  the proven polygon/submission path.

Hypothesis: each visible model has a persistent `t3DVisual_Model` identity
and a persistent selected `tModel0` identity, providing a semantic seam above
generic polygon preparation.

## Analysis and promotion rule

Correlate, in sequence:

```text
t3DVisual_Model this
  -> selected tModel0 this
  -> manager source pointer / polygon list
  -> 0x006AB410
  -> batch flush
  -> DrawIndexedPrimitive
```

Group parent and child pointers across frames and verify their vtable values
against the static RTTI identities. PASS-level promotion requires persistent
model/mesh ownership plus downstream correlation; it does not imply ship
gameplay identity unless separately proven. A pointer without matching RTTI and
call-chain behavior is insufficient.

## Completed run and adjudicated result

Run `20260904-104217` used SFCLauncher 2.1.0.22, sponsor-approved UAC,
one tactical scene containing the player ship and at least one other visible
ship, one camera rotation, one target change, and normal exit. It recorded the
profile maximum of 6,364 samples in 64.718 seconds with
`stop_reason=process_exit`. The CSV was 1,412,572 bytes, below the 2 MB stop.

Two stable visual/mesh chains were distinguished and both converged through
manager `0x04980038` into 1,500 generic submissions, 1,000 batch flushes,
and 1,000 indexed-draw call sites. Separate static caller reconstruction then
identified the captured parent pointers as `tEntityShip` instances using RTTI
COL `0x007BF2A8`, vtable `0x00796F0C`, visual field `+0x88`, and the
render owner at `0x004162B9`. This separately satisfies the gameplay-identity
condition in the promotion rule.

Evidence files are `M0-RT-003.csv`, `M0-RT-003-summary.json`,
`M0-RT-003-evidence.md`, and `loaded-modules.csv` beneath
`artifacts/pre-m0/runs/20260904-104217`.
