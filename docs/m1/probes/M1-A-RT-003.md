# M1-A-RT-003 — Initial Microstutter Attribution

## Question and hypothesis

Did the 3–5-second initial microstutter reported during `M1-A-RT-002` arise from
the extremely hot `0x006AB410` observation hook, or does it remain when only the
five semantic/lifetime hooks are active?

**Hypothesis:** omitting installation of the downstream geometry hook while
leaving the confirmed semantic hooks unchanged removes the transient stutter.
If so, hot-path hook overhead is the supported cause. If the stutter remains,
component activation/semantic observation or ordinary tactical-entry loading
remain unresolved candidates.

## Configuration and bounds

- Component/schema: 0.2 / `m1.semantic.v1`; exact hook architecture unchanged.
- Installed hooks: scene begin, ship owner, visual model, Model0, visual exit.
- `0x006AB410`: never patched; the controller still verifies its original bytes
  at removal.
- Tactical arm occurs only after the sponsor reports entry.
- Maximum 3,000 scene epochs, 50,000 retained events, eight owners, 60 seconds.
- Event log: 16 MiB warning, 32 MiB hard stop; expected below 15 MiB.
- Stop on frame/event/time bound, restore hooks, then normal sponsor exit.
- Exact client hashes and launcher baseline remain required.

Command:

```powershell
pwsh -NoProfile -File tools/m1_component/start_m1_enabled_session.ps1 `
  -MaxSeconds 60 -MaxFrames 3000 -MaxEvents 50000 -DisableGeometryHook
```

## Sponsor observation

Enter the same two-ship skirmish, report tactical entry for arming, and operate
normally for the bounded window. Report whether any stutter occurs and whether
it is at tactical entry/component activation or later during steady operation.
Also report rendering, HUD, cursor, targeting, camera, movement, or control
anomalies.

## Interpretation

- No stutter with semantic-only hooks: hot downstream hook overhead becomes a
  **STRONG HYPOTHESIS**, corroborated by the prior 32.4-million-call count.
- Stutter remains: downstream hook is rejected as the sole cause; a paired
  disabled/activation-timestamp test remains necessary.
- This attribution run intentionally provides no new downstream correlation;
  that correlation is already confirmed by `M1-A-RT-001/002`.

No result from this probe changes CDD requirements or establishes formal TRL 4.

## Runtime result — 2026-09-06

Run `20260906-155210-enabled` installed only the five semantic/lifetime hooks;
the summary confirmed `geometry_hook_enabled=false` and zero geometry-hook
events. Across approximately 28 seconds and 3,000 scene epochs, two owners each
retained one stable ship, visual, Model0, and source identity. No semantic
rejection, vtable mismatch, owner/thread overflow, retirement, or truncation
occurred. The known `0x00509843` path occurred 3,001 times, approximately once
per scene epoch, and remained finite/unassigned.

The component restored every installed hook, and the controller verified all
six known sites—including the never-patched geometry address—contained their
original bytes. The sponsor reported no initial stutter, later stutter, or other
visible issue. SFC exited normally, exact client hashes remained unchanged, and
no game-directory or arm-signal file remained. Total output was 7,835,834 bytes.

Comparison with `M1-A-RT-002`, which reported a 3–5-second initial stutter while
the geometry hook processed 32,409,660 calls, supports the downstream validation
hook as the stutter cause at **STRONG HYPOTHESIS** confidence. Semantic-component
activation and steady semantic observation are rejected as sufficient causes
under this fixture. Precise frame-time magnitude remains unmeasured, but the
user-visible attribution question is resolved sufficiently for the sub-gate.

Combined `M1-A-RT-001/002/003` evidence establishes neutral semantic operation,
two-owner differentiation, lifetime retirement/fresh reappearance, stable
motion-time association, prior downstream correlation, clean removal, and
non-interference when the diagnostic geometry hook is absent. Decision:
**M1 CONTINUES — SEMANTIC INTEGRATION SUB-GATE PASS**. Formal TRL 4 PASS remains
prohibited; the intrusive geometry hook is retained only as a bounded diagnostic
mechanism and is not part of the practical semantic component boundary.
